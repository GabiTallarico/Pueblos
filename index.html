Experiencias de pueblos originarios con el INTA

Mapa de experiencias. Registro de 1° ronda de relevamiento

Octubre 2026  · 

Este tablero muestra las experiencias de trabajo conjunto entre comunidades indígenas y el INTA: dónde se desarrollan, qué acciones incluyen, cómo participaron las comunidades y qué aprendizajes dejaron. Use los filtros para explorarlas; el mapa, las fichas y los gráficos se actualizan con cada selección. Solo se publican experiencias con consentimiento y se resguardan los datos personales de las comunidades.
